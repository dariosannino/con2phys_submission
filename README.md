# con2phys analysis

```
py-files/<mouse>/   raw data, one folder per mouse (1-18); never written to
c2p/                shared code
  data.py           Recording: loads one mouse; mice(), iter_recordings()
  stats.py          hierarchical bootstrap (mice -> units), CIs
  plots.py          area colours
  qNN_*.py          computation for question NN (cached to results/)
  questionnaire.py  record_answer() -> results/answers.json; fill_pdf() -> docs/questionnaire_filled.pdf
notebooks/
  00_exploration.ipynb   one mouse in detail (set MOUSE)
  qNN_*.ipynb            plots, tests and the questionnaire answer for question NN
results/            cached per-unit tables and answer tables (qNN_*.csv)
docs/questionnaire.pdf
```

Use the `con2phys` kernel.

**Questionnaire.** `docs/questionnaire_filled.pdf` is rebuilt from `results/answers.json` by `c2p.questionnaire.fill_pdf()`
(the blank `docs/questionnaire.pdf` is never changed). Confidence and expected-consensus ratings are stored with
`record_meta(q, confidence=..., consensus=...)`. Prior-experience ratings (page 17) entered directly in the filled PDF are read back by `fill_pdf()` before each rebuild, so they are preserved. To recompute a question from the raw files, call `qNN.compute(force=True)`.

## Setup and reproduction

1. **Environment**: `conda env create -f environment.yml`, then register the kernel:
   `conda run -n con2phys python -m ipykernel install --user --name con2phys --display-name con2phys`.
2. **Data**: download the con2phys dataset (Python/`.npy` version) from the organisers and extract it so that each mouse
   is in `py-files/<mouse>/` (`spikes.npy`, `clusters.npy`, `brain_area.npy`, `waveforms.npy`, `lfp_1-3.npy`,
   `trial_data.csv`). The data are not part of this repository.
3. **Run**: open the notebooks with the `con2phys` kernel. Every `qNN.compute()` reads its cached result from `results/`
   if present; `compute(force=True)` recomputes from the raw data. From a terminal:
   `jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=con2phys notebooks/q01_firing_rate.ipynb`
   (naming the kernel explicitly matters: VS Code may reset the notebook's kernel name to `python3`).
4. The questionnaire answers are written by the last cell of each question notebook into `results/answers.json`, and
   `c2p.questionnaire.fill_pdf()` rebuilds `docs/questionnaire_filled.pdf` from the blank form.

Not in the repository: the dataset (`py-files/`) and `results/q03_events.csv` (530 MB, regenerated by
`c2p.q03_ripples.compute(force=True)`).

Decision rule: an area is answered only if it beats both other areas in the per-mouse paired Wilcoxon test after Bonferroni correction (x3); otherwise "Not enough data / no differences".
